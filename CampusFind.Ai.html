A few safety tips

  • Don't publish passwords, full ID numbers or private details.
  • For valuable items, verify ownership before handing them over.
  • Meet in a public campus location or ask campus staff for help.
  • Never post someone else's personal information without permission.
Please verify the item's description and ownership before arranging its return. Your cooperation helps keep our campus community safe.

How it works

  1. 1
    Post a report
    Choose Lost or Found and add basic details.
  2. 2
    Search the noticeboard
    Use the search box and category filter to find a possible match.
  3. 3
    Verify and return
    Check the item's details and arrange a safe handover.

Project problem statement

Students can misplace everyday belongings around classrooms, libraries, cafeterias and sports areas. Without one organised noticeboard, finding the owner or locating an item can take time.

Our solution: a simple web page that organises sample lost and found posts, allows searching and filtering, and lets users add a report.

Built with HTML, CSS and beginner-friendly JavaScript for a CSE-326.
